Kapasitas Throughput & Standar Link Fisik

Throughput lokal mengukur real bandwidth antara komputer klien dengan laptop server di ruang server/LAN.

  • ≥ 600 – 1000 Mbps (Grade A+): Sangat Baik. Full Gigabit link 1000Base-T (4-pair 8-pin Cat5e/6). Sangat aman untuk PACS/DICOM dan SIMRS.
  • > 150 – 600 Mbps (Grade A): Baik. Support Gigabit / Wi-Fi 5GHz. Aman untuk operasional normal.
  • 50 – 150 Mbps (Grade B): Cukup. Terindikasi limit Fast Ethernet 100 Mbps. Rentan antrean jika file besar dibuka bersamaan.
  • < 50 Mbps (Grade C/D): Kurang Baik. Bahaya! Segera periksa fisik kabel, terminasi pin tester, outlet wallplate, atau Access Point.
